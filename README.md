# Python、后端与数据库

从零开始的 Python 后端开发课程 —— 面向零基础学员，一步步走到能写数据库、能做后端服务。

> 本仓库是课程配套资料，包含课堂笔记、示例代码与作业。跟着 `notes/` 一节一节学即可。

## 课程简介

本课程从 Python 语言基础讲起，逐步过渡到数据库与后端开发，适合两类学员：

- **零编程基础者**：想掌握 Python 与 SQL，胜任数据分析、取数、报表类工作。
- **有一定基础者**：想系统学习 Python 后端（数据库 / API / 工程化）。

课程主线是一条循序渐进的路径：

```
Python 基础  →  数据库 (MySQL)  →  网络通信  →  后端框架 (Flask / FastAPI)  →  工程化与实战
```

其中 **Python 基础 + 数据库** 是所有人都需要掌握的核心；后续的网络与后端框架部分面向希望深入后端开发的学员。

## 开发环境

- **Python 3**（请安装 3.10 及以上版本，安装时勾选 *Add to PATH*）
- **PyCharm**（社区版免费，本课程主用 IDE）
- **MySQL**（数据库部分使用）

## 课程大纲

### 第一部分　Python 编程基础
入门与环境搭建、变量与数据类型、数据结构、控制流、函数与模块、面向对象、异常与文件处理。

### 第二部分　数据库（MySQL）
SQL 查询、多表关联与聚合、增删改与建表、索引与事务、用 Python 连接数据库。

### 第三部分　网络通信
HTTP 协议、请求与响应、REST 风格 API。

### 第四部分　Flask 框架
路由与视图、请求处理、最小可运行的 Web 服务。

### 第五部分　FastAPI 框架
异步、Pydantic 数据校验、自动接口文档、ORM 与数据库集成。

### 第六部分　工程化与实战
项目结构、依赖管理、测试、部署，完整后端服务实战。
